The datasets are too large to be included in this Git repository. Please refer to the following links:

- [eLife dataset](https://huggingface.co/datasets/BioLaySumm/BioLaySumm2025-eLife): Official eLife dataset provided by the BioLaySumm 2025 organizers.
- [PLOS dataset](https://huggingface.co/datasets/BioLaySumm/BioLaySumm2025-PLOS): Official PLOS dataset provided by the BioLaySumm 2025 organizers.
- [SUWMIT dataset](https://huggingface.co/datasets/whopriyam2/SUWMIT-dataset): This dataset includes our interim and processed data, but it excludes the final abstractive summaries.
